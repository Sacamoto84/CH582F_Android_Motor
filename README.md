# Контроллер помпы для 19-литровой бутыли

Помпа на аккумуляторе, управляется ручкой и кнопкой на корпусе. Телефон нужен
только для настройки и наблюдения — без него устройство полностью работает.

| Папка | Что там |
|---|---|
| [CH582F_MotorBLE](CH582F_MotorBLE) | Прошивка контроллера. Чип CH582F (RISC-V, WCH), плата WeAct CH57x/CH58x Core Board, питание 1S Li-ion, мотор 0.7 А |
| [Android](Android) | Приложение для настройки: телеметрия, 12 параметров, мастер подбора стартового рывка, калибровка вольтметра |

## Связь между частями

Обмен идёт по BLE через два характеристика: команды пишутся в `0xFFE1`,
телеметрия и ответы приходят уведомлениями на `0xFFE2`. Источник истины по
протоколу — [`APP/include/app_proto.h`](CH582F_MotorBLE/APP/include/app_proto.h);
если документация ему противоречит, прав заголовок.
